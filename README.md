# Tag-udregner-prod

For at starte PROJ - til Jeres udregner  // Mvh K.N

Lav En .env.local fil i Root mappen ( Tag-udregner-prod) med følgende:


DATAFORDELER_API_KEY="indsæt jeres egen api key fra Data fordeler"
DATAFORDELER_DAR_URL=https://graphql.datafordeler.dk/DAR/v3
DATAFORDELER_BBR_URL=https://graphql.datafordeler.dk/BBR/v3
DATAFORDELER_GEODKV_URL=https://graphql.datafordeler.dk/GeoDanmarkVektor/v2



Vær' opmærksom på at det tager 15min efter at i har aktiveret nøglen før at apien er aktiv



2. Sørg for at have node på jers pc installeret https://nodejs.org/en/download



3. Kør npm install i Root mappen (Tag-udregner-prod )


4. Kør npm run dev for at starte app
